sequenceDiagram

actor RES as Resident
participant LOCKER as «subsystem»<br/>Locker Access System
participant LISTENER as «service»<br/>MqttLockerListenerService
participant SVC as «service»<br/>ReturnRequestService
participant ALLOC as «service»<br/>CompartmentAllocationService
participant DB as «database»<br/>Database
participant PUSH as «service»<br/>PushNotificationService
participant HUB as «service»<br/>OperationsRealtimeNotifier
participant APP as «boundary»<br/>Resident Mobile App

Note over RES,APP: Process: Complete Return Parcel Deposit & Dispatch Pickup Code Notification
Note over RES,APP: Precondition: Compartment was opened for return deposit; ReturnCode was pre-generated at request creation; resident places item and closes door

RES->>LOCKER: Place item inside compartment and close door
activate LOCKER

LOCKER-->>LISTENER: Publish MQTT Event: DoorClosed (lockers/{deviceId}/doors/{channel}/status)
deactivate LOCKER
activate LISTENER

LISTENER->>DB: Query active successful return access event
activate DB
DB-->>LISTENER: LockerAccessEvent (ReturnRequestId, LockerCompartmentId)
deactivate DB

LISTENER->>SVC: FinalizeDepositAsync(returnRequestId, completedAt, ct)
activate SVC

SVC->>DB: Query ReturnRequest by id (Include ResidentProfile, AllocatedCompartment)
activate DB
DB-->>SVC: ReturnRequest entity (ReturnCode, Status = Allocated)
deactivate DB

alt ReturnRequest is not in Allocated state or no compartment
  rect rgb(254,226,226)
    SVC-->>LISTENER: InvalidOperationException / Ignore
  end
else ReturnRequest is Allocated
  rect rgb(220,252,231)
    SVC->>ALLOC: ReleaseAsync(null, returnRequestId, completedAt, ct)
    activate ALLOC
    ALLOC->>DB: Mark CompartmentReservation ReleasedAt = completedAt
    activate DB
    DB-->>ALLOC: Reservation released
    deactivate DB
    deactivate ALLOC

    SVC->>DB: Update ReturnRequest Status = Deposited, ResidentDepositedAt = completedAt
    SVC->>DB: Enqueue Notification with pre-generated ReturnCode
    SVC->>DB: Record AuditLog (ReturnRequest.Deposited)
    activate DB
    DB-->>SVC: Changes committed
    deactivate DB

    SVC->>PUSH: TrySendAsync(pushNotificationId, ct)
    activate PUSH
    PUSH-->>APP: Dispatch Push Notification: "Return parcel stored. Shipper code: {ReturnCode}"
    deactivate PUSH

    SVC->>HUB: PublishToUserAsync(residentUserId, RealtimeEvent)
    activate HUB
    HUB-->>APP: Realtime event broadcast
    deactivate HUB

    SVC->>HUB: PublishToLockerAsync(lockerId, RealtimeEvent)
    activate HUB
    HUB-->>SVC: Realtime event broadcast
    deactivate HUB

    SVC-->>LISTENER: Finalize completed
  end
end

deactivate SVC
deactivate LISTENER
