```mermaid
sequenceDiagram

actor RES as Resident
participant LOCKER as <<subsystem>><br/>Locker Access System
participant LISTENER as <<service>><br/>MqttLockerListenerService
participant SVC as <<service>><br/>ReturnRequestService
participant ALLOC as <<service>><br/>CompartmentAllocationService
participant DB as <<database>><br/>Database
participant PUSH as <<service>><br/>PushNotificationService
participant APP as <<boundary>><br/>Resident Mobile App
participant HUB as <<service>><br/>OperationsRealtimeNotifier

Note over RES,HUB: Process: Complete Return Deposit & Confirm Pickup Code
Note over RES,HUB: Precondition: Compartment was opened for return deposit; resident places item and closes door

RES->>LOCKER: Place item inside compartment and close door
activate LOCKER

LOCKER-->>LISTENER: Publish MQTT Event: DoorClosed (LockerCode, CompartmentCode)
deactivate LOCKER
activate LISTENER

LISTENER->>DB: Query active successful return access event
activate DB
DB-->>LISTENER: Access event (ReturnRequestId, CompletedAt)
deactivate DB

LISTENER->>SVC: FinalizeDepositAsync(returnRequestId, completedAt, ct)
activate SVC

SVC->>DB: Query ReturnRequest by id
activate DB
DB-->>SVC: ReturnRequest entity
deactivate DB

alt ReturnRequest is not in Allocated state
  rect rgb(254,226,226)
    SVC-->>LISTENER: Invalid return state (Ignore / No-op)
  end
else ReturnRequest is Allocated
  rect rgb(220,252,231)
    SVC->>ALLOC: ReleaseAsync(null, returnRequestId, completedAt, ct)
    activate ALLOC
    ALLOC->>DB: Mark CompartmentReservation Released
    activate DB
    DB-->>ALLOC: Released
    deactivate DB
    deactivate ALLOC

    SVC->>DB: Update ReturnRequest Status = Deposited & DepositedAt = completedAt
    SVC->>DB: Enqueue Notification with Pickup Code for Resident/Shipper
    activate DB
    DB-->>SVC: Changes committed
    deactivate DB

    SVC->>PUSH: TrySendAsync(notificationId, ct)
    activate PUSH
    PUSH-->>APP: Push notification dispatched
    deactivate PUSH
    APP-->>RES: Display Alert: "Return parcel deposited! Pickup code: {code}"

    SVC->>HUB: NotifyReturnRequestUpdatedAsync(returnRequest)
    activate HUB
    HUB-->>SVC: Realtime broadcast sent
    deactivate HUB

    SVC-->>LISTENER: Finalize completed
  end
end

deactivate SVC
deactivate LISTENER
```
