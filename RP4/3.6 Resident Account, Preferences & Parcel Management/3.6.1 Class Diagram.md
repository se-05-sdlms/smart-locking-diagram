%% =========================================================
%% APPLICATION RELATIONSHIPS
%% =========================================================

AuthController --> IAuthService : delegates
ResidentsController --> IResidentService : delegates

IAuthService <|.. AuthService : implements
IResidentService <|.. ResidentService : implements

AuthService --> IOtpService : issues and verifies
AuthService --> ApplicationDbContext : reads and writes
ResidentService --> ApplicationDbContext : reads and writes

AuthController ..> RegisterRequest : receives
AuthController ..> LoginRequest : receives
AuthController ..> AuthTokenResponse : returns
ResidentsController ..> UpdateResidentProfileRequest : receives
ResidentsController ..> ResidentProfileResponse : returns

%% =========================================================
%% DOMAIN RELATIONSHIPS
%% =========================================================

User "1" -- "0..1" ResidentProfile : has
User "1" --> "0..*" RefreshToken : owns
User "1" --> "0..*" OtpChallenge : challenges

%% =========================================================
%% PERSISTENCE RELATIONSHIPS
%% =========================================================

ApplicationDbContext ..> User
ApplicationDbContext ..> ResidentProfile
