%% =========================================================
%% APPLICATION RELATIONSHIPS
%% =========================================================

AdminController --> IAdminService : delegates
UsersController --> IUserService : delegates
SystemPoliciesController --> ISystemPolicyService : delegates
AuditLogsController --> IAuditLogService : delegates
ReportsController --> IReportService : delegates

IAdminService <|.. AdminService : implements
IUserService <|.. UserService : implements
ISystemPolicyService <|.. SystemPolicyService : implements
IAuditLogService <|.. AuditLogService : implements
IReportService <|.. ReportService : implements

AdminService --> ApplicationDbContext : reads
UserService --> ApplicationDbContext : reads and writes
SystemPolicyService --> ApplicationDbContext : reads and writes
AuditLogService --> ApplicationDbContext : reads
ReportService --> ApplicationDbContext : reads

%% DOMAIN RELATIONSHIPS

User "1" --> "0..*" OperatorAssignment : assigned to
OperatorAssignment "0..*" --> "1" Locker : operates
User "1" --> "0..*" AuditLog : performs

ApplicationDbContext ..> SystemPolicy
ApplicationDbContext ..> AuditLog
