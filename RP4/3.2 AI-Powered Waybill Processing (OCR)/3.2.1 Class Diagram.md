%% =========================================================
%% APPLICATION RELATIONSHIPS
%% =========================================================
DeliveryRequestsController --> IDeliveryRequestService : submits recipient info
ImagesController --> IImageStorageService : uploads image
IDeliveryRequestService <|.. DeliveryRequestService : implements
IImageStorageService <|.. LocalImageStorageService : implements
IImageStorageService <|.. SupabaseImageStorageService : implements
DeliveryRequestService --> ApplicationDbContext : validates and saves
DeliveryRequestService --> ITokenHashService : validates guest token
DeliveryRequestService --> IPushNotificationService : manual approval notification
DeliveryRequestsController ..> SubmitDeliveryRequest : receives
DeliveryRequestsController ..> DeliveryRequestSummaryResponse : returns body

%% =========================================================
%% DOMAIN RELATIONSHIPS
%% =========================================================
DeliveryRequest "0..*" --> "0..1" ResidentProfile : recipient
DeliveryRequest "0..*" --> "1" Locker : guest session locker
DeliveryRequest "0..*" --> "1" SystemPolicy : snapshots policy
ResidentProfile "1" --> "1" User : account
ResidentProfile "0..*" --> "0..1" Locker : registered locker

%% =========================================================
%% PERSISTENCE RELATIONSHIPS
%% =========================================================
ApplicationDbContext ..> DeliveryRequest : persists
ApplicationDbContext ..> ResidentProfile : queries
ApplicationDbContext ..> User : checks phone and active role
ApplicationDbContext ..> Locker : queries
ApplicationDbContext ..> SystemPolicy : queries
