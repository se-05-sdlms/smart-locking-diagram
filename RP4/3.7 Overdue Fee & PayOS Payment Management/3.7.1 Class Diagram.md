%% =========================================================
%% APPLICATION RELATIONSHIPS
%% =========================================================
OverdueChargeWorker --> IOverdueChargeService : calculates every 15 minutes
IOverdueChargeService <|.. OverdueChargeService : implements
OverdueChargeService --> ApplicationDbContext : reads parcels and updates hourly fees

PaymentWebhooksController --> IPaymentGatewayService : verifies signature
PaymentWebhooksController --> IResidentSubscriptionService : activates subscription
IPaymentGatewayService <|.. PayOSPaymentGatewayService : implements
IResidentSubscriptionService <|.. ResidentSubscriptionService : implements
ResidentSubscriptionService --> IPaymentGatewayService : creates subscription checkout
ResidentSubscriptionService --> ApplicationDbContext : saves and activates subscriptions
PaymentWebhooksController ..> PayOSWebhookPayload : receives
PayOSPaymentGatewayService ..> CreatePaymentLinkRequest : accepts
PayOSPaymentGatewayService ..> CreatePaymentLinkResult : returns
PayOSPaymentGatewayService ..> PayOSWebhookData : verifies and returns
ResidentSubscriptionService ..> PayOSWebhookData : checks amount and order

%% No overdue-payment orchestration or Paid update is implemented in this checkout.
%% PaymentTransaction is a persisted entity; do not connect the subscription webhook to it.

%% =========================================================
%% DOMAIN RELATIONSHIPS
%% =========================================================
Parcel "1" --> "1" DeliveryRequest : delivery
DeliveryRequest "0..*" --> "1" SystemPolicy : applied policy
Parcel "1" --> "0..1" OverdueCharge : incurs
OverdueCharge "1" --> "0..*" PaymentTransaction : payment attempts
Parcel "1" *-- "0..*" ParcelStatusHistory : records

%% =========================================================
%% PERSISTENCE RELATIONSHIPS
%% =========================================================
ApplicationDbContext ..> Parcel : persists
ApplicationDbContext ..> DeliveryRequest : queries policy link
ApplicationDbContext ..> OverdueCharge : persists
ApplicationDbContext ..> SystemPolicy : queries
ApplicationDbContext ..> PaymentTransaction : maps entity
ApplicationDbContext ..> ParcelStatusHistory : persists
ApplicationDbContext ..> ResidentSubscription : persists
