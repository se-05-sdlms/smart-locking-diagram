%% APPLICATION RELATIONSHIPS

ParcelsController --> IParcelService : delegates
IParcelService <|.. ParcelService : implements
ILockerAccessService <|.. LockerAccessService : implements

ParcelService --> ApplicationDbContext : reads and writes
LockerAccessService --> ApplicationDbContext : records access
